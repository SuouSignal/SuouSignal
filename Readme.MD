## 🎮 Currently building

### `InnocentSin: REDUX`

A **native port of the PSP game via static recompilation** — no emulator in the
loop. The original MIPS binary gets lifted and recompiled into native code, so
the game runs as a real executable on modern hardware.

It's a learning project as much as a technical one: I'm new to reverse
engineering, and this is me getting my hands dirty with disassembly, MIPS
semantics, and the messy reality of console hardware quirks.

```
  PSP MIPS binary  ──▶  static recompilation  ──▶  native executable
       (ELF)              (lift + retarget)            (runs bare)
```

#### 🎮 No que estou trabalhando

**[`InnocentSin: REDUX`](https://github.com/SuouSignal/InnocentSin-REDUX)** — um **port nativo do jogo de PSP por recompilação
estática**, sem emulador no meio do caminho. O binário MIPS original é
levantado e recompilado em código nativo, então o jogo roda como um
executável de verdade em hardware moderno.

reversa, e esse é o meu jeito de meter a mão na massa com disassembly,
semântica de MIPS e as esquisitices de hardware de console.
