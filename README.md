## Featured project

### 🎬 [CatchTS](https://github.com/SuouSignal/CatchTS)

An educational Chrome and Edge extension that detects directly accessible media files and unencrypted HLS streams loaded by webpages.

**Highlights:**

- Detects MP4, WebM, MOV, M4V, and unencrypted HLS streams
- Automatically selects the highest-resolution HLS variant
- Supports simultaneous downloads with an automatic queue
- Provides progress tracking through a persistent browser side panel
- Built with Manifest V3 and standard browser-extension APIs

> CatchTS is intended exclusively for educational and lawful use with authorized media.
